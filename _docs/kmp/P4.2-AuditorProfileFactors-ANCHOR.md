### 3.2 Budget, planchers

Budget, `AuditorProfileFactorGate.combinedTargetBudgetMgdl` L212–216, study = tip = source :

```
error = bgMgdl - workingTargetMgdl
si error <= 0 ou non fini → 0
room = isfEffectiveFactor / 0.85 - 1
budget = max(0, error * room)
```

`0.85` est `AuditorProfileFactorLimits.FACTOR_MIN`, pas un littéral dans cette fonction.

`targetForDoseSite` (L255–268) refait ce budget sur la cible du site. Direction protectrice (`requested > 1`) : `scaleTargetForDose`. Direction hausse : `drop = min(target × (1 − requested), budget)` puis `max(lowered, min(target, 80))`.

`isfLowerBound` (L301–304) : le plus haut de 5,0 mg/dL/U, de la moitié du profil (`× 0.5`), et du plancher stress s’il est fini et `> 0`. Profil statique inconnu et facteur `< 1` : `applyIsfFloor` L87–95 force `effective = 1.0`, jeton `no_profile_static`, `applied = false`.

### 3.3 Refus de hausse

`raiseRefusals` (gate L331–362) ne court que si `requested < 1.0`. Toutes les règles s’ajoutent ; aucune ne s’arrête à la première.

À l’arrivée, le validateur (identique au tip) clamp d’abord dans `[0.85, 1.15]`. `checkRaiseEvidence` L196–218 refuse en plus, pour la hausse seulement : glucides ou COB `> 0.5` ou mode repas ; `mealSupport` ; hypothèse concurrente ≠ `"none"` ; ISF impliquée absente ; ISF impliquée `>= 0.85 ×` ISF moteur ; chute de glycémie `> 5.0` mg/dL sur la fenêtre ; glycémie de fin `< 120`.

`BooleanKey.OApsAIMIAuditorProfileFactors` : clé `key_aimi_auditor_profile_factors`, défaut `false`, dépendance `AimiAuditorEnabled`. Le texte UI (study `strings.xml` L605–606, tip L603–604) est le même, y compris « at most 15 % » et « under 120 mg/dL ».
