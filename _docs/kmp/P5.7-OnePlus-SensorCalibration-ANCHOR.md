## ASYNC IMPACT

Aucun nouveau `CoroutineScope` et aucun nouveau dispatcher. `ioScope` du plugin n’est pas touché. `calibrateSensor` est synchrone : il retourne avant toute file tant que le switch est off.

`sendPendingCalibration` tourne dans `OnePlusEgvSession.run`, déjà bloquant sur `bleExecutor`. Il ne construit `0x34` que si une valeur a été acceptée dans la file. Le switch off empêche cette acceptation. L’attente de réponse (`CALIBRATION_REPLY_ROUNDS` = 3, 10 s chacune) n’est atteinte qu’après une écriture réussie, donc seulement si le switch a été allumé et qu’une valeur a passé les gardes.
