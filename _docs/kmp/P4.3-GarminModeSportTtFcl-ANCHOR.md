## 3. Détail des gestes

### 3.1 NOTE, mot-clé seul

`onPostMode` du tip (L757–769) :

1. `mode` trim + lowercase ;
2. refus si vide ou hors ensemble ;
3. durée par défaut, puis parse, puis `coerceIn(0, 480)` ;
4. `postTherapyMode(rawMode, duration)` ;
5. si `fcl`, `postTempTarget(80.0, 30)` ;
6. JSON `{"ok":true,"mode":"…","duration":…}` avec la durée rapportée, y compris `0`.

`GarminTherapyMode.decide` (L78–99) fait les étapes 1–3 et 5–6. `GarminPlugin.onPostMode` (L410–430) fait l’étape 4 et n’appelle `postTempTarget` que depuis `decision.tempTarget`.

`postTherapyMode` des deux côtés ignore un mot-clé vide après trim, recalcule la durée stockée, écrit `note = mot-clé`, `type = NOTE`, `enteredBy = "Garmin Widget"`, `duration` en millisecondes. Le texte n’est jamais `"sport 120"`.

### 3.2 `sport` : 120 min, sans temporary target

Durée absente ou `SPORT` : 120. Durée `120` : 120. Durée `900` : 480 à la réponse et au stockage. Aucun `TempTarget`. Le test HTTP du tip (`GarminPluginTest.kt` L494–498) vérifie `postTherapyMode("sport", 120)` et `times(0)` sur `postTempTarget`. Le study a les mêmes deux vérifications (`GarminPluginTest.kt` L393–397).

`findActiveSportEvents` arme `sportTime` pour `note.contains("sport")` tant que `now <= timestamp + duration`, sauf si la note contient aussi `walk` ou `marche`. La note écrite est `"sport"`, donc elle arme. `walk` n’est pas un mode montre.

### 3.3 `fcl` : 30 min + TT 80 mg/dL pendant 30 min

`FCL` sans durée : mode 30, note `"fcl"`, cible 80 pour 30. `fcl` avec `duration=45` : la NOTE part pour 45 min, la cible reste 80 pour 30. Les deux constantes ne sont pas lues dans la query.

`postTempTarget` non nul : raison `WEAR`, low = high = `convertToMgdl(80.0, unités du profil)`, durée `30 * 60_000` ms, source `Garmin`. L’annulation (`target == 0` ou `duration == 0`, source `TTDialog`) est le corps du tip (L244–253). `/mode` ne l’atteint pas : le seul appel study passe 80 et 30.

`findActiveFclEvents` garde la note au moins 60 min (`max(duration, FCL_MIN_WINDOW_MS)`), des deux côtés, et ce fichier n’est pas dans le diff. Le plafond `declared` demande la note fcl, l’absence de note sport, et une cible ≤ 85 mg/dL. 80 ≤ 85. Une note sport vive rend `declared` faux.
