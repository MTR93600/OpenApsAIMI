## 3. Fidélité clinique vs tip

### 3.1 Helper — latch episode-bound, reduce/hold only

Relu côte à côte `a546722609:plugins/aps/src/main/.../risk/MealConfirmedEarlyReleaseLatch.kt` (blob `579d6df221`, = `11f064`) vs `0d4547d7dc:plugins/aps/src/commonMain/.../risk/MealConfirmedEarlyReleaseLatch.kt` (blob `7af53e59`).

Diff réel : `object` → `internal object`. **Zéro** changement de formule. `diff` après substitution de visibilité : **vide**.

Règles (ordre, identiques) :

1. Si pas encore latched et `armedThisTick` → `armedSeen = true` (n’arme **pas** le hold).
2. Si pas `armedSeen` ou pas `tailTripped` → état inchangé. Une chute sans arm préalable **n’est pas** une queue post-pic.
3. Trip → `latched = true`, `iobAtTripU = max(stack, MIN_TRIP_IOB_U=3.0)`, `armedSeen = true`.
4. Une fois latched : `releases` si `bg < target + 20` **ou** `iob ≤ iobAtTripU × 0.5` → `State()` (oublie `armedSeen`).
5. Marge glucose **stricte** `<` (égalité `target+20` **tient** le latch). Fraction IOB **`<=`** (égalité **relâche**).
6. NaN / IOB négatif au trip → plancher 3.0 U. BG non fini → ne relâche pas.

Le breaker IOB (`tailByIob`) est **volontairement non latched** : `tailTripped = tailByPhase || tailByFall` seulement. Identique tip DPA L219–221 ≡ study L220–221.

Dose : l’objet est **pur** (pas d’horloge, pas d’état instance). Il ne calcule aucune U. Le seul geste dose-facing est `mcerTailLatched` dans le breaker DPA, qui peut seulement **empêcher** `armed`.

`335ce` n’est **pas** le contrat porté : latchait toute chute tant que MCER était enabled, sans `armedSeen`, sans `MIN_TRIP_IOB_U`. Study = `11f064` / tip.
